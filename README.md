# Yatra Kerala — Next.js field guide

A responsive Next.js + React + TypeScript guide to lesser-known places across all 14 districts of Kerala.

## Run locally
```bash
npm install
npm run dev
```

## Discovery features
- Interactive Leaflet map using OpenStreetMap tiles and destination pins
- Search, district and experience filters
- Save places locally in the browser
- Destination detail sheets with access notes, activities, navigation-by-name and references
- Editorial hidden-gem score (uniqueness 45%, accessibility 30%, activity/visitor-interest proxy 25%)
- Responsive Emerald / Spring Celadon visual design and reduced-motion support

## Editorial and data quality — read before travel
- The current collection covers all 14 districts, but it is a starter guide, not a complete gazetteer.
- **Map pins are reference points, not a claim of surveyed GPS accuracy.** Some pins still need destination-level confirmation. Navigation opens a place-name search rather than forcing an unverified coordinate.
- The score is an editorial comparison, not a live popularity or review ranking. The activity-interest component is a proxy based on the range of listed experiences; no visitor analytics are claimed.
- A destination-specific photograph is shown only where a corresponding Wikimedia Commons image was identified. Other cards use an illustrated placeholder rather than pretending a generic stock image depicts the destination. Each supplied photo links to its Commons source/credit page; check the file page for the exact licence and attribution before reuse.
- Some history/context notes still need destination-specific archival, local-government, archaeological or community references. Where a reference is not attached, treat the note as provisional; oral traditions are not presented as verified history.
- Opening status, access permissions, weather, boating, trekking, camping and forest entry can change. Confirm with the relevant local authority/operator before travel. Do not enter private land, closed trails or restricted forest areas.
